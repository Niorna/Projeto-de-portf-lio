# Bancada Leonardo

Site portfólio de conserto de **PCs e notebooks**, feito por **Leonardo João Ramos Gomes** em parceria com o pai.

🔗 **Site no ar:** https://niorna.github.io/Projeto-de-portf-lio/

## Sobre o projeto

A ideia do site é mostrar o trabalho de bancada de pai e filho: o que eles consertam, as ferramentas que usam e como cada serviço é feito. O projeto foi desenvolvido por um estudante de Ciências da Computação da UDF, usando apenas HTML, CSS e JavaScript.

## O que o site tem

- Visual em preto e roxo, com topo fixo que brilha ao rolar a página
- Ficha de serviço de exemplo na página inicial
- Seção "Sobre mim" com idade, curso e a história com o pai
- Abas de **PC** e **notebook** com os defeitos mais comuns
- Cards das ferramentas da bancada
- Galeria de fotos dos consertos
- Passo a passo de como o serviço funciona
- Botão que abre direto o WhatsApp
- Layout responsivo, que se adapta ao celular, com menu próprio para telas pequenas
- Elementos que aparecem suavemente ao rolar a página
