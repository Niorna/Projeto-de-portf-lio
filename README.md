## Publicar no GitHub Pages
1. Crie um repositório no GitHub e envie todos os arquivos.
2. Vá em Settings > Pages.
3. Em Source, escolha "Deploy from a branch", branch `main` e pasta `/ (root)`.
4. Aguarde um minuto: o site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
